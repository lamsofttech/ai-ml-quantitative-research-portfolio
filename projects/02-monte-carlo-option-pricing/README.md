# Monte Carlo Option Pricing and Risk Analysis

Planned scope: reproducible vectorized geometric Brownian motion; European option estimates checked against Black–Scholes; confidence intervals; Value at Risk; Greeks and sensitivity analysis; and a Dockerized Streamlit application.

Results will explicitly separate pricing-model accuracy from investment performance. Assumptions—including log-normal returns, constant volatility, risk-free rates, and simulation error—will be tested and documented. This project will own its dependencies rather than adding them to a repository-wide environment.
