# Machine Learning for Credit-Risk Prediction

Planned scope: schema and range validation; class-imbalance analysis; logistic-regression baseline; tree-based models; probability calibration; threshold analysis; SHAP-style explanations; subgroup fairness checks; and a containerized FastAPI prediction service.

The model card will distinguish discrimination, calibration, and business utility. It will document dataset representativeness, proxy discrimination, human oversight, adverse-impact risks, drift, and the limits of automated credit decisions.
