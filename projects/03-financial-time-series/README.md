# Financial Time-Series Forecasting

Planned scope: naive and classical statistical baselines; lagged and rolling features; walk-forward validation; a tree-based ML model; explainability; and comparison using predictive and decision-relevant metrics.

All features will be timestamp-audited. Fitting, scaling, and tuning will occur inside each training window to prevent look-ahead bias. Results will document data provenance, regime sensitivity, uncertainty, transaction costs where relevant, and why forecast accuracy alone does not establish a profitable strategy.
