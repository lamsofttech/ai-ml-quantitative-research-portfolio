# Interpolation node design and conditioning — November 20, 2026

This deterministic experiment compares equally spaced and Chebyshev-Lobatto
nodes while separating polynomial approximation error from float64
representation/evaluation error and estimating interpolation sensitivity. It
uses the known Runge function

$$f(x)=\frac{1}{1+25x^2},\qquad -1\le x\le 1,$$

so every interpolated value can be compared with a known truth. No historical
or private data is used.

## Design

- Equally spaced nodes and Chebyshev-Lobatto nodes
  $x_j=-\cos(\pi j/n)$, both including -1 and 1.
- Polynomial degrees 4, 8, 12 and 16 (5, 9, 13 and 17 nodes).
- 401 equally spaced evaluation points.
- An 80-decimal-digit barycentric calculation defines the reference
  interpolation polynomial for each represented node set.
- The production `lagrange_interpolate` function evaluates the same nodes and
  values in NumPy float64.
- At each grid-estimated Lebesgue maximum, every supplied value is perturbed by
  exactly $10^{-6}$ with the sign of its cardinal basis value. This
  deterministic, bounded, worst-case construction should attain the recorded
  grid-based amplification bound; it is not a random-noise model.

Chebyshev-Lobatto interior nodes are generated by the standard library cosine
in float64, then converted exactly to `Decimal` for the reference. This makes
the comparison isolate polynomial approximation and float64 evaluation for the
same represented nodes; it does not claim exact symbolic cosine values.

The two error components are:

1. **Approximation error:** true Runge value minus the high-precision polynomial.
2. **Floating-point error:** float64 production result minus the same
   high-precision polynomial.

The conditioning diagnostic is the **Lebesgue function**

$$\Lambda_n(x)=\sum_{j=0}^n |L_j(x)|.$$

Its maximum over the evaluation grid estimates the worst-case factor by which
small perturbations in supplied values can be amplified by interpolation. It
depends on the nodes, not on the Runge function values. A value near 1 means
little amplification; a large value signals a sensitive interpolation design.

Exact configuration, source hashes, environment and row-level values are in
[stability.json](stability.json).

## Results

| Node design | Degree | Maximum approximation error | Maximum float64 discrepancy | Estimated Lebesgue constant |
|---|---:|---:|---:|---:|
| Equidistant | 4 | 0.438357 | 3.33e-16 | 2.208 |
| Equidistant | 8 | 1.045174 | 1.44e-15 | 10.941 |
| Equidistant | 12 | 3.657717 | 6.61e-14 | 89.253 |
| Equidistant | 16 | 14.363078 | 7.82e-13 | 933.090 |
| Chebyshev-Lobatto | 4 | 0.459950 | 3.29e-16 | 1.799 |
| Chebyshev-Lobatto | 8 | 0.204678 | 2.76e-16 | 2.275 |
| Chebyshev-Lobatto | 12 | 0.084392 | 5.34e-16 | 2.539 |
| Chebyshev-Lobatto | 16 | 0.036713 | 4.79e-16 | 2.724 |

At degree 16, Chebyshev-Lobatto placement reduces the measured maximum
approximation error by about 391 times (99.74%) compared with equally spaced
nodes. Its endpoint clustering controls the boundary oscillation that causes
the equidistant Runge failure. The Chebyshev error also falls as degree grows
from 4 to 16, while the equidistant error grows sharply.

This is not a claim that Chebyshev nodes are always better at every small
degree: at degree 4 their measured maximum error is about 4.9% larger. It is
evidence that node placement matters and that adding nodes alone does not
guarantee a better global polynomial. For both designs, approximation error is
far larger than the float64 discrepancy, so the improvement is not caused by
switching numerical precision.

## Conditioning interpretation

At degree 16, the estimated Lebesgue constant is 933.090 for equally spaced
nodes and 2.724 for Chebyshev-Lobatto nodes. The equidistant design therefore
has a roughly 343-times larger measured worst-case amplification bound on this
grid. Most perturbations need not be amplified by exactly that factor; it is
an upper-bound diagnostic over possible sign patterns in the supplied values.

The bounded perturbation experiment makes that statement observable. With
each node value changed by at most $10^{-6}$, the deliberately aligned sign
pattern changed the degree-16 interpolated output by 0.000933090 for equally
spaced nodes and 0.000002724 for Chebyshev-Lobatto nodes:

| Node design | Target | Maximum input perturbation | Observed output change | Observed amplification |
|---|---:|---:|---:|---:|
| Equidistant | -0.965 | 1.0e-6 | 9.330899e-4 | 933.090 |
| Chebyshev-Lobatto | -0.100 | 1.0e-6 | 2.723812e-6 | 2.724 |

Both observed amplification factors match the corresponding grid-estimated
Lebesgue constants to the recorded precision. This is an intentionally
adversarial construction demonstrating attainability at the selected grid
point, not evidence that typical measurement error has this sign pattern.

The contrast explains why endpoint clustering is valuable beyond this one
Runge-function result. The equidistant estimate grows from 2.208 to 933.090 as
degree increases, while the Chebyshev-Lobatto estimate grows slowly from 1.799
to 2.724. The error comparison shows what happened for the selected function;
the Lebesgue diagnostic shows how node placement controls sensitivity to value
errors more generally.

## Limitations

This study covers one difficult function, one interval, two node designs and
four degrees. The 401-point grid estimates the continuous maximum error and
Lebesgue constant; it does not prove either exact supremum between grid points.
The 401/801/1601 sensitivity check reduces concern about this particular grid
choice but still does not provide a continuous optimization proof.
The bounded local searches reduce the remaining between-grid uncertainty but
still do not prove that no higher maximum exists in an unselected interval.
The 80-digit reference is a strong numerical benchmark, not a symbolic proof. Interior
Chebyshev-Lobatto nodes use the platform's float64 cosine values. Absolute
errors are reported; relative error near small function values would answer a
different question. No extrapolation, splines, stochastic noise distribution
or empirical measurement process is evaluated.
