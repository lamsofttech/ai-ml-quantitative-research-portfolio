## Why this improves the portfolio

A link checker proves that an evidence file exists, but not that the employer
narrative still tells the truth about that file. The new validator closes that
gap. If a future experiment changes a reported SE, RMSE, coverage count or exact
interval, CI now requires the case study to be reviewed instead of silently
leaving a stale headline result.

This is reproducibility and research-governance evidence: the public explanation
is now coupled to the machine-readable result. It does not create new market,
forecasting or profitability evidence.
